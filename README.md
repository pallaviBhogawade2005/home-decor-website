🏠 CasaNest – Modern Home Decor Website

CasaNest is a modern and responsive home decor e-commerce website designed to provide users with a beautiful and simple shopping experience.

The website is built using HTML, CSS, and JavaScript with a focus on responsive design, interactive features, animations, and clean UI.

✨ Features
🏠 Modern and attractive homepage
📱 Fully responsive design
🛋️ Home decor product collection
🔍 Product search functionality
❤️ Wishlist functionality
🛒 Add-to-cart counter
🌙 Dark/Light mode
📩 Newsletter subscription
📱 Mobile navigation menu
✨ Smooth animations
🎨 Modern UI design
📊 Product categories
📖 About/brand section
📞 Contact section
🛠️ Technologies Used
HTML5 – Website structure
CSS3 – Styling, responsive design and animations
JavaScript – Interactive functionality
Font Awesome – Icons
Google Fonts – Typography
